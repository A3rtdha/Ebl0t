# 🤖 Discord Multi-Bot (Project Name)

Многофункциональный Discord-бот для администрирования, развлечений и автоматизации серверов. 
**Текущий фокус (Core Feature):** Продвинутая система создания и проведения кастомных игр по **Valorant**.

## 🌟 Основные возможности (Valorant Customs)
- 🎮 Интерактивный интерфейс: современные `/slash` команды, Эмбеды (Embeds), Кнопки, Выпадающие списки (Dropdowns) и Модальные окна (Modals).
- 🔊 Автоматическое управление голосовыми каналами (создание комнат ожидания, раскидка по командам, удаление каналов).
- ⚖️ Балансировщик команд на основе внутреннего рейтинга игроков (в будущем — полноценная ELO-система).
- 🎲 Два режима игры: **RANDOM** (быстрый старт) и **VOTED** (турнирный драфт с капитанами).
- 📊 Сбор и запись статистики матчей (победители, счет через удобные всплывающие окна).
