# 🗺 Дорожная карта разработки (Roadmap)

## Этап 1: Фундамент бота 🏗️
- [ ] Инициализация проекта и подключение к Discord API.
- [ ] Настройка обработчика слэш-команд (Slash Command Handler).
- [ ] Создание структуры локальной БД (JSON) для хранения данных пользователей (ID, ник, ранг, сыгранные матчи).
- [ ] Написание базовой команды `/custom` с отправкой приветственного Embed-а с выбором режима (RANDOM / VOTED).

## Этап 2: Система лобби и комнат ожидания 🚪
- [ ] Логика пинга роли `@valorant`.
- [ ] Автоматическое создание голосового канала "Ожидание (#)".
- [ ] Отслеживание захода/выхода игроков в этот голосовой канал.
- [ ] Кнопка "ВСЕ ГОТОВЫ" (Host-only), защита кнопки от нажатия другими игроками (эфемеричные/личные сообщения об ошибке).
- [ ] Валидация: проверка на четное количество игроков и наличие их в БД (добавление новых).

## Этап 3: Режим RANDOM 🎲
- [ ] Генерация красивого Embed-а со списком участников.
- [ ] Логика балансировки команд (`TEAM`): распределение с учетом ранга, назначение сторон (Атака/Защита).
- [ ] Логика карт (`MAP`): выбор 3 случайных карт, создание 3 кнопок, выбор карты хостом.
- [ ] Логика агентов (`AGENT`): полный рандом агентов для всех.
- [ ] Реализация кнопки `[REROLL]` агента под главным Эмбедом: безлимитный реролл, который локально обновляет агента для нажавшего пользователя.

## Этап 4: Режим VOTED (Драфт) 🏆
- [ ] Тайное голосование за капитанов команд: рассылка эфемеричных выпадающих списков, подсчет голосов, рандомизатор при ничьей.
- [ ] Выдача временных прав капитанам (Зеленые/Красные кнопки в интерфейсе).
- [ ] Логика агентов (`AGENT`): рандом по пресетам ролей (например: обязательный страж и смокер на команду).
- [ ] Логика карт (`MAP`): реализация выпадающего списка (Dropdown) для поочередного бана карт капитанами.

## Этап 5: Жизненный цикл матча ⚔️
- [ ] Таймер на 10 секунд перед стартом.
- [ ] Создание голосовых каналов "Команда 1" и "Команда 2".
- [ ] Массовый мув (перемещение) игроков из комнаты "Ожидание" в каналы команд.
- [ ] Удаление канала "Ожидание".
- [ ] Уведомление в чат с тегами игроков (GL HF).
- [ ] Слэш-команда `/stop` для хоста: вызов Модального окна (Pop-up формы) для ввода победителя и счета. Запись в БД.

## Этап 6: Глобализация (В будущем) 🚀
- [ ] Перенос БД с JSON на полноценную SQL/NoSQL базу.
- [ ] Внедрение сложной системы ELO (с весами за победу/поражение/счет).
- [ ] Система лидербордов на сервере.
